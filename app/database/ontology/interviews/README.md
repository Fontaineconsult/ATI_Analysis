# Interview guides

One-page prep guides generated by `/stakeholder-interview` — one per scheduled
stakeholder interview, named `<date>-<campus>-<topic-slug>.md`.

Lifecycle: generated from graph recon before the interview (follow-ups, open
Queries, SI coverage targets) → used live as the crib sheet → read back by
`/ontology-ingest` when the transcript lands in `../raw_transcripts/`, which
reports coverage against the guide's targets. Keep guides after ingest: the
"not reached" targets seed the next guide for that campus/topic.
