# Extracts

Context packets generated by `/ontology-extract`, one per external consumer and
topic, named `<date>-<consumer-slug>-<topic-slug>.md`. A `.json` sidecar of the
same stem sits beside the Markdown when the consumer is code.

Each file opens with a header that says when it was generated, which academic
year it describes, which anchors and filters it used, which registry queries it
ran, and how the consumer re-pulls the data. The body is written for the reader
named in the brief. Every fact in a packet was graded before it left the graph
(source text, administered fact, curated description, attested note, or derived),
and the header says what was withheld and why.

A packet is a dated snapshot. When the consumer needs fresh rows, the deliverable
is a `read` entry in `app/database/cypher_runner/query_registry.yaml`, which the
MCP server exposes as a tool of the same name, and the packet here records which
queries to call.
